# 關於 Jardi

**Jardi - Location Tool™** 是一款 Mac 上的 iPhone 虛擬定位工具。從單一座標、收藏地點，到沿線移動與圖片座標整理，希望讓日常操作更清楚、更順手。

**Jardi - Location Tool™** 名稱源自作者小禾的 threads 帳號名 [@jardiniere_pkm](https://www.threads.com/@jardiniere_pkm) ，取前五個字母，而 jardiniere 則是取自法文 jardinière 女園丁的意思。

## 資料如何處理

路線、CSV 編輯與圖片偵測在 Mac 上處理，定位指令透過本機連線傳給 iPhone。App 沒有把你的路線、CSV 或圖片上傳到自建伺服器的功能，也沒有分析追蹤服務。僅在 App 更新時，需要存取 Github 更新來源。
