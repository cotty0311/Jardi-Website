# About Jardi

**Jardi - Location Tool™** is a Mac app for simulating an iPhone's location. It brings together destinations, saved places, route movement, and image coordinate tools.

The name comes from the first five letters of the author's Threads username, [@jardiniere_pkm](https://www.threads.com/@jardiniere_pkm). “Jardiniere” is inspired by the French word *jardinière*, meaning a female gardener.

## How data is handled

Routes, CSV editing, and image detection are processed on the Mac. Location commands reach the iPhone through a local connection. The app has no feature that uploads your routes, CSVs, or images to a custom server, and no analytics tracking service.

Some features need network access: developer-image preparation may download files from GitHub, image personalization may request device-signing data from Apple, Mac location access uses macOS location services, and app updates access the update source.
