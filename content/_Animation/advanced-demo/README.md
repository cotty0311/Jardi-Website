# Jardi Route Demo v3

將自己的 `plain.png`、`pin.png`、`footprint.png`、`avatar.png` 放入 `images/`，開啟 `index.html`。

- 預設載入立即開始；預設 repeat 勾選，因此會循環播放。取消 repeat 後，完整跑一次即結束。
- 開始：只有停止或播放完成後可按，重新從起點播放並清除舊足跡。
- 暫停：只在播放中可按，凍結時間、位置、足跡。
- 繼續：只在暫停時可按，從暫停處繼續。
- 停止：在播放中或暫停時可按，停在當前位置、保留足跡。
- 重置：隨時恢復預設設定並立刻重新播放。
- fast：每個點停留約 1 秒再跳至下一點；每個到達的 pin 下都留下足跡。
- Orbit：起始點先繞圈，每個點都繞正圓並沿路留下足跡。
- speed：1–20，預設 15，即時調整；fast 的等待時間不受 speed 影響。
- pin.png：圖片底部中央對準座標。若 PNG 有透明邊，需裁掉或微調 CSS。

程式以 `script.js` 頂部的 `pins` 百分比座標為例；依實際地圖修改。

Orbit 現在以整個圓周連續動畫計算，和直線路徑使用相同像素速度（同受 speed 控制）。
